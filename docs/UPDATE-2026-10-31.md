## TON

Получатель по умолчанию: `UQAnvk0ZBh884n9Sb_vBg05do10BXIBl6URoBBMBWgSNtQAj`.

Для смены адреса задайте **`TON_DEPOSIT_WALLET`** в переменных окружения сервера и перезапустите приложение. Адрес проверяется по формату, mainnet-флагу и CRC16. Для отключения пополнения задайте пустое значение. Ключей кошелька приложение не требует и не хранит.

Для рабочего TON Connect нужны HTTPS `DOMAIN`/`PUBLIC_URL` и `BOT_TOKEN` вашего приложения. Манифест отдаётся по `/tonconnect-manifest.json`; SDK `@tonconnect/ui` 5.0.1 находится локально в `frontend_patch/vendor/`. Подключение кошелька и подтверждение отправки выполняет пользователь.

Сервер создаёт персональный счёт после проверки подписанного Telegram initData. Сумма хранится целым числом нанотонов. У каждого счёта уникальный комментарий; адрес фиксируется при создании счёта. Ответ клиента или BOC от кошелька не зачисляет баланс. Кнопка проверки сверяет входящую транзакцию через TON Center: адрес, сумму, комментарий, время, отсутствие bounced/aborted и повторного использования хеша. `TONCENTER_API_KEY` рекомендуется для надёжного доступа к индексатору. Ошибка индексатора оставляет платёж ожидающим.

Баланс TON относится только к данному независимому приложению. Пополнение официального аккаунта MRKT, доставка Stars, вывод и игровые расчёты не подключены. Реальный перевод при разработке не выполнялся.

После повторного открытия формы сервер возвращает баланс и последние ожидающие счета данного пользователя. Для восстановления проверки перевода не требуется хранить Telegram initData или ключи кошелька в браузере.

Источники реализации: [TON Connect](https://docs.ton.org/applications/ton-connect/get-started), [TON Center transactions](https://docs.ton.org/ecosystem/api/toncenter/v3/blockchain-data/get-transactions).

## Подарки, коллекции и ассеты

Сохранены 133 каталожные коллекции, 7 806 моделей и 80 фонов с исходными метаданными. `/api/gift-collections` возвращает этот каталог. Это справочник типов подарков, а не доказательство владения уникальными экземплярами.

Модели загружаются без изменения байтов с указанного в каталоге публичного CDN в серверный кеш `DATA_DIR/gift-art`. Витрина обращается к `/api/gift-assets/<collection>/<index>`. Произвольные внешние адреса endpoint не принимает. Для предварительного скачивания всех моделей:

```text
python cache_gift_assets.py --all
```

Это может потребовать нескольких сотен МБ и времени. Архив содержит метаданные и исходные ресурсы интерфейса; все 7 806 изображений заранее в архив не включены. При обычной работе кеш наполняется по мере просмотра.
