# 500 NFT из публичной галереи MRKT Bank

Источник: вкладка «Подарки» профиля [@mrktbank](https://t.me/mrktbank) в Telegram Web, открытая в Edge 2 ноября 2026 года. В выборку входят ровно 500 разных NFT. Номер и название каждого экземпляра прочитаны в его карточке. Это ограниченная выборка по запросу пользователя; полный инвентарь Bank не экспортировался. Сбор занимает время, поэтому принадлежность и метаданные относятся ко времени наблюдения каждого предмета.

- `frontend_patch/mrktbank-nfts.json` — постоянные ссылки `t.me/nft/...`, исходные TGS-ссылки, время наблюдения и доступные атрибуты. `selection_complete` подтверждает только выборку из 500, `profile_inventory_complete` остаётся `false`.
- `frontend_patch/mrktbank-links.txt` — 500 постоянных ссылок, по одной на строку.
- `frontend_patch/mrktbank-animation-links.txt` — прямые ссылки на оригинальные TGS-анимации.
- `frontend_patch/bank-current.js` — эти же 500 экземпляров для витрины. Ранее сохранённые 94 рыночных объявления остаются в `catalog-current.js` и `catalog-snapshot.json` как отдельное наблюдение.

Публичные NFT-страницы Telegram содержат оригинальную анимацию в `<source type="application/x-tgsticker">`. TGS — gzip с Lottie JSON. Ссылки на CDN могут перестать работать; постоянная ссылка на NFT сохраняется. Сервер загружает анимацию только для NFT из проверенного манифеста, проверяет адрес CDN и размер, декодирует TGS и кеширует JSON в `DATA_DIR/bank-nft-animation`. При недоступности сохранённого CDN-адреса он получает новый с той же публичной NFT-страницы. Кеш не включён в Git.

TGS содержит модель; фон и символ хранятся отдельно. Для совпадающих коллекции и модели используется уже проверенная исходная анимация. В таких строках `animation_source_nft` указывает NFT-источник, а `animation_match` — способ сопоставления. Это не меняет постоянную ссылку конкретного экземпляра. Для Myth Mask Red Oni проверены `MythMask-79395` и `MythMask-172161`: оба исходных TGS имеют размер 60 022 байта и SHA-256 `a5aa771720da8e4cde0d5ad1d1435bc81668ec7c7ef89d9f085c103129bfc1c2`.

Если публичная NFT-страница не отдаёт файл или модель уже определена в галерее, используется опубликованный TGS из [индекса Gift Changes CDN](https://cdn.changes.tg/gifts/models/), который уже используется проектом для изображений. Адрес копируется из индекса соответствующей коллекции по точному имени наблюдавшейся модели. Файл проверяется как gzip/Lottie; в манифесте сохраняются источник, SHA-256 декодированного JSON, размер и число кадров. `Myth Mask/Red Oni.tgs` с этого CDN также совпал байт в байт с обоими файлами Telegram выше. Эти ресурсы отмечены `animation_source: giftchanges_model_cdn`.

Восстановлена прежняя полная карточка NFT с изображением, атрибутами, флорами и боковыми кнопками. Упрощённое окно для импортированных предметов больше не используется. Анимация воспроизводится в существующей области изображения; при загрузке или сбое остаётся превью. Используется локальный `lottie-web` 5.13.0, сборка canvas без выражений; источник, SHA-256 и лицензия находятся в `frontend_patch/vendor/`. Режим уменьшенного движения останавливает анимацию.

Наличие NFT в галерее Bank не устанавливает цену продажи. Эти 500 карточек открываются через «Подробнее» и «Открыть в Telegram»; цена не заменяется нулём, корзина и предложение для таких экземпляров отключены. Флоры коллекции показываются из сохранённого каталога в GRAM и не являются ценой конкретного NFT. В режиме подключённого рыночного API действуют существующие правила обновления живой витрины.

Обновление прямых ссылок из сохранённого списка:

```text
python tools/resolve_nft_links.py --input frontend_patch/mrktbank-nfts.json --output work/mrktbank-refreshed.json
python tools/resolve_model_animations.py --input frontend_patch/mrktbank-nfts.json --output work/mrktbank-refreshed.json --cache-dir work/model-animation-checks
python tools/build_bank_catalog.py --input work/mrktbank-refreshed.json --limit 500
python prepare_frontend.py unpack
```

Для принудительного обновления уже сохранённых CDN-ссылок используйте новый выходной JSON. При повторе с тем же выходным файлом утилита продолжает недостающие/ошибочные ссылки. Необходимы только публичные ссылки, без сессии Telegram и данных входа. Ограничение 500 проверяется сборщиком каталога. Автоматическая публикация и деплой для этой работы не запускались.

Документация проигрывателя: [Lottie loadAnimation](https://github.com/airbnb/lottie-web/wiki/loadAnimation-options).
